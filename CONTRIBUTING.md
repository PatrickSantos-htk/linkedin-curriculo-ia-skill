# Como contribuir

Que bom que você quer ajudar! 🙌

## Ideias de contribuição
- Adaptar a skill ou os exemplos para outras áreas (saúde, jurídico, educação, engenharia...)
- Melhorar o checklist ou o modelo de currículo
- Novos layouts de banner
- Correções de texto

## Como enviar
1. Faça um fork do repositório.
2. Crie uma branch: `git checkout -b minha-melhoria`
3. Faça as alterações e um commit com uma mensagem clara.
4. Abra um Pull Request explicando o que mudou e por quê.

Prefere não mexer em código? Abra uma **Issue** com a sugestão.

## Regras
- Mantenha o princípio central: **nenhuma sugestão pode incentivar inventar ou inflar qualificações.**
- Não adicione automação ou raspagem de dados do LinkedIn.
- Exemplos devem usar pessoas e empresas **fictícias**.
